# Conclusion {#sec:conclusion}

The Witness Register was built to answer one question: can four independent
instruments co-exist in a shared record without any of them losing authority
over its own vocabulary? The answer is yes, but only because the register
refuses to do almost everything a reader might expect of a shared record. It
does not rank. It does not average. It does not merge. It does not score. It
does not judge; [@prop:non-compensatory] enforces this in code. It holds
envelopes beside one another, records authored relations as separate entries,
keeps history append-only and sealed ([@prop:append-only]), and on request
emits one bounded posture ([@def:projection]) carrying the digest of the exact
state that earned it and the reasons it holds.

The register's mechanisms are small and each is borrowed from an older
tradition — linked timestamping, transparency logs, non-compensatory decision
rules, provenance vocabularies, boundary objects. The scholarship section
([@sec:scholarship])
names what is taken and where each borrowing stops. What is new is not the
mechanisms but the refusal: the register assembles them into an instrument
that co-registers without aggregation, and the non-compensatory invariants
([@prop:non-compensatory]) are enforced in code, not merely stated in prose. The method section
([@sec:method]) documents the construction, the formal core
([@sec:formalism]) states the register's properties as objects and rules,
and three further propositions ([@sec:further-formalism]) establish that
chain verification is complete ([@prop:chain-verification-completeness]),
return contracts constrain the projection across chains
([@prop:return-contract-constraint]), and projection is deterministic for
identical inputs ([@prop:projection-determinism]) — each verified by the
test named in its binding table row. The examples section
([@sec:examples]) exercises the register against real data.

The 3×3 canonical witness battery ships as an executable test that every
check rejects its own falsified variant, so a green grid is evidence the
checks can fail, not only that they passed. The worked co-registration uses
four real envelopes generated by running each line's own public API on its
own shipped example, and the honest structure over them — four different
subjects — is an incomparability relation and a held posture, not a crown.
The return was then met the way the contract said it must be, and completing
it lifted exactly the return hold and nothing else.

Black Line remains the positive operating discipline. Golden Line holds the
aspirational thread. Red Line is the refusal boundary. White Line marks
absence, restraint, and unknowability. The Witness Register stands beside
the set, not among them: it has no colour, no substantive question of its
own, and no verdict. Its motto is *precedence without information
destruction*; *no crown without return*. It lives at `docxology/witness_register`,
beside the rest of that index.
