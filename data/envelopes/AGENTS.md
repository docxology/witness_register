# Envelopes contract

Real `line.report-envelope/1.0` records are stored by value. Historical
examples and older cohort bytes stay unchanged. New public-producer exports
bind immutable source snapshots; private producers contribute only separately
disclosure-reviewed synthetic exports with empty source references and no
private provenance. No line package is imported here.

See [`README.md`](README.md) for provenance records and generation commands.
