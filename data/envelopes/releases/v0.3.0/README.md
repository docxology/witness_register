# Native worked-export transport cohort — 0.3.0

This cohort carries eight native-generated synthetic worked envelopes from exact
producer snapshots. Fixture review dates are preserved; registration on
2026-11-07 does not make the native examples fresh evidence about a common subject.
Package versions are separate from native registry and evaluator identifiers.

The registrar records `CANNOT_COMPARE` and `RETURN_DUE` with an open subject-
correspondence contract. The examples retain their different native subjects;
none is reclassified as a shared-subject assessment. No aggregate native verdict,
consent, permission, or authority is established by successful transport.

Replay this committed transport packet from a Witness Register checkout:

```bash
uv run python scripts/build_release_cohort.py data/envelopes/releases/v0.3.0
```

The builder checks exact exported byte hashes, common-envelope admission and
line attribution, then verifies its state chain and derives its projection.
It does not dereference native report pointers, rerun native evaluators, verify
producer commits, or establish shared-subject correspondence. Producer generation
and source custody were checked separately by the release operator.

`manifest.json` preserves public producer commits and actual export recipes.
Violet's separately reviewed export is only the synthetic common envelope;
its source identity, implementation, native assessment/history and release
receipts remain private. Its empty source-reference collection remains empty.
Hashes and identifiers are not anonymity guarantees or disclosure clearance.

The retained `v0.2.0` cohort and its bounded-wait history remain unchanged.
