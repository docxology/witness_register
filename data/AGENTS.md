# Data contract

The `data/` directory holds stored records consumed by the register's test
suite and figure builders. Nothing here is generated at runtime — every file is
a committed artifact with provenance.

## Envelopes

`envelopes/` carries four real `line.report-envelope/1.0` records, one per
line, each generated by running that line's own public API on 2026-07-29 and
stored here by value. The register reads these envelopes through
`intake_envelope()` and never imports any line package.

See `envelopes/README.md` for the generation commands and provenance record.
