# Manuscript contract

Markdown sources for the Witness Register paper. Figures embed from
`output/figures/` via the figure registry generated by `witness_register.figures`.

- `config.yaml` — title, authors, publication metadata, page geometry for template rendering.
- Section files (`01_*.md` …) — prose, equations, and figure references.
- `references.bib` — bibliography consumed by the template rendering engine.
- Cover image is generated by `witness_register.figures.cover_plate` and written
  to `output/figures/wr_cover.png` by `scripts/build_figures.py`.

The register is a sixth work beside the line set: it co-registers report
envelopes without aggregation, ranking, or override. The manuscript describes
the design, the formalism, the scholarship context, and the limits.

Regenerate figures here, then re-render through the external template engine
after changing captions, digest bindings, or analysis-derived numbers.
